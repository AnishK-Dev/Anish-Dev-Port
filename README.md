# Anish-Dev-Port Website 🚀

Welcome to the repository for my personal portfolio website! This project serves as my digital workspace—a clean, responsive showcase of my journey in Computer Science and Engineering, my technical skill set, and the live applications I have built.

The live website is hosted for free via **GitHub Pages**.

---

## ✨ Features

*   **Responsive Layout:** Fully optimized for mobile, tablet, and desktop viewing.
*   **Project Showcase:** Dedicated section linking to my interactive web utilities and desktop programs.
*   **About Me & Skills:** A summary of my core competencies, academic milestones, and engineering focus areas.
*   **Contact Section:** Clean integration of professional handles (GitHub, LinkedIn, Email).

---

## 🛠️ Built With

*   **Structure & Semantics:** HTML5
*   **Styling & Layout:** CSS3 (Flexbox/Grid, Responsive Media Queries)
*   **Interactivity:** Vanilla JavaScript
